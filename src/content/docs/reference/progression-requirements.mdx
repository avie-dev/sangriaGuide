<FilterTable placeholder="Filter by system or requirement…">

| To use… | You need |
|---|---|
| Your first class (free) | The tutorial quest *The Path of Blood* |
| Other classes, class switching | *The Path of Blood* finished |
| Sangrael | Draekhar at Evolution I |
| La Muerte | Draekhar III, Sepulkros III, Carmesyne II |
| General | Umbrellis II, Mortak III, Bastien III |
| Class evolutions | The class active; Ourosangue for the tribute |
| Meditation (MEDITATE button) | The starter tutorial finished; a path chosen; 0.35 Sangricoin |
| Summoning pets | The initial tutorial finished |
| Quitina double XP | A class chosen in the tutorial |
| Personal teleports, the Sangria Bank brazier | Vlad Parker's quest *The Blood Baptism*; a castle (yours or your clan's) |
| Vault | Viktor's quest *Worthy of a Vault* |
| Mobile Depot | Owning a vault |
| Dungeons | A group of 2–4, each with a key of the tier; the starter tutorial finished (to be invited) |
| Rift Incursions (seeing them) | An Eye of Twilight in your or your clan's castle |
| Reality Rupture | Level 90 |
| Goreswine's Judgment | Level 90; 3–5 players |
| Tower of the Immortals | One of the 11 classes; talking to the Herald once |
| Character prestige | Level 90; Ourosangue in the Bank |
| Weapon or blood prestige | Level 100 on the item in hand or the active blood |
| Vampiric Schools | Character prestige 20 |
| Pulses | Prestige 20 and level 90 (quest *The Call of Blood*) |
| Transfusions | 10 Pulses + 10,000 Ourosangue (8,000 VIP); *The First Transfusion*; Echo quests for sealed ones |
| Kill Points | 250 transfusions |
| Fortification | At least 1 prestige in the craft (up to your prestige) |
| Refinement rows 1–3 / 4 / 5 | Craft prestige 7 / 9 / achievement + prestige 10 (or rows 1–2 via the achievement) |
| Selling profession services | 5 prestiges in your active craft |
| Refining components from gathering | Gathering prestige 5 |
| Sacrificed Souls from gathering | Gathering prestige 6–9 |
| Pet Cristais | Pet tier T1+ (T0 can't evolve) |
| Luminance / Thanatos achievements | 10 / 30 transfusions |
| Pillar of Megara | 3 of the other 4 Pillars |

</FilterTable>
