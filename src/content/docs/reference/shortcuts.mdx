## Panel hotkeys (interface only)

| Key | Opens | Page |
|---|---|---|
| F1 | Profile | [Profile](/character/profile/) |
| F2 | Pets | [Pets](/companions/pets/) |
| F3 | Quests | [Quests](/quests/quests/) |
| F4 | Professions | [Professions](/professions/) |
| F5 | Bank | [Bank](/economy/bank/) |
| F6 | Mail | [Mail](/world/mail/) |
| F7 | Sangrulhos | [Sangrulhos](/companions/sangrulhos/) |
| F8 | VIP | [VIP](/support/vip/) |
| F9 | Achievements | [Achievements](/world/achievements/) |
| F10 | Meditation | [Meditation](/meditation/how-it-works/) |
| F11 | School | [Schools](/schools/) |
| F12 | Transfusion (plasmas) | [Plasmas](/endgame/plasmas/) |
| L | Market (only inside the city) | [Market](/economy/market/) |
| G | Store bag items in castle chests | [Castle](/world/castle/) |
| = | Chest Management (castle) / vault list (vault) | [Castle](/world/castle/) |

**Esc** closes the open panel, and the key that opened a panel also closes it. Rebind keys in the game's **Controls** options tab. Panels also open from their NPC or by command. Without the interface there are no hotkeys, and everything goes through chat (`.menu`).

## Other keys

| Key | Where | Does |
|---|---|---|
| F | Anywhere | Interact with NPCs, tanks, boards |
| X (while downed) | Dungeons, Arena, Rupture | **Gives up**: you die, lose the reward, and drop your item bag |
| Q / E | Placing furniture or an aquarium | Rotate |
| C / T | Placing furniture or an aquarium | Raise / lower |
| R twice | Placing furniture | Remove the piece under the cursor |
| Space | Placing | Finish or cancel |
| Right-click a player | Near them, still, out of combat | View profile, invites, Engagement |
| Right-click your bag | With a vault's Mobile Depot | Open the Mobile Depot |

## Emotes

| Emote | Does |
|---|---|
| Taunt | Opens the Shadow Merchant |
| Clap | Summons your last pet, or puts it away |
