| Market shop | 5,000 Ourosangue, once |

| Illusory Arena entry | 2,000 (Standard) / 8,000 (Guided) Ourosangue |
| Sangrulho fusion | 2,000 Ourosangue |
| Sangrulho incubation speed-ups | +1h 15 · +6h 80 · +24h 300 Sangricoins |
| Pet Cristais REDISTRIBUTE | 15,000 Ourosangue |
| Pet Cristais RESET | 75 Sangricoins |
| Plasma Reset | 50 Sangricoins |
| Pillar echo (each of 4) | 200,000 Ourosangue |
| Pillar of Megara tribute | 200,000 Ourosangue |
| Casino spin | 500 to 3,000 Ourosangue |
| Furniture piece | 30 to 250 Sangricoins |
| Aquarium (Fisher craft) | 2,000 Ourosangue + 20 Iron Ingots, 20 Glass, 50 Oil, 1 The Fish |
| Aquarium food | 100 Ourosangue + 2 Fish Bones, 10 Oil each |
