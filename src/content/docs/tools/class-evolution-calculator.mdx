## How it works

- **Tributes:** 15,000, 30,000 and 45,000 Ourosangue for Evolutions I–III of any class.
- **Prerequisites:** Sangrael needs Draekhar I; La Muerte needs Draekhar III, Sepulkros III and Carmesyne II; General needs Umbrellis II, Mortak III and Bastien III. The calculator adds what's missing, prerequisites first.
- **Switching:** unlocking a class through its Master's quest makes it active for free. Going back to a class you already own costs **3,000**. It assumes you finish each class before moving on, which keeps switches to a minimum.

Unlock quests can only start after *The Path of Blood*. See [Class evolutions](/classes/evolutions/).
