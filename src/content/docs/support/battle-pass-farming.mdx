These suggestions are this wiki's, built from the official pass XP values. <Label type="community" />

## What each activity is worth

| Activity | Pass XP | Limit |
|---|---|---|
| Rupture win, Nightmare | 70 (top of the 20–70 range) | One rewarded win per window, 3 windows a day |
| Rupture win, Adventurer | 20 (bottom of the range) | Same |
| Judgment win | 50 | One rewarded win per day |
| Open-world V Blood | 2–10 | Respawn timers |
| Tower boss | Half the normal value, killer only | — |
| Illusory Arena | 0 | — |

The guide gives the Rupture's range (20–70) but not each difficulty's exact value. The table assumes the range runs from Adventurer to Nightmare.

## Suggestions

1. **Win the Rupture in every window you're online for**, at the hardest difficulty you can beat on the first try. It gives Sangricoins and Ourosangue too, and a help run gives no pass XP.
2. **Do the Judgment once a day.**
3. **Hunt V Bloods in a group.** Pass XP isn't split: everyone nearby and in combat gets the full value. Pin targets in the Boss Tracker to catch respawns.
4. **Skip the Arena** if pass XP is your goal.
5. **Claim as you go**, and keep 10 inventory slots free.

Exact per-boss values aren't published. Stronger bosses are worth more.
