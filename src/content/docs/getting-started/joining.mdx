## Steps

<Steps>

1. **Decide whether to use the interface.** It's free and optional but makes the server much easier to play. If you want it, install it first by following [Installing the interface](/getting-started/interface/). With the launcher installed, you start the game from the launcher's **PLAY** (JOGAR) button so the mods stay up to date.

2. **Open V Rising** and go to the server list.

3. **Search for "Sangria Falls"** and join the server you want. This wiki targets **[GLOBAL] Sangria Falls [RPG 04] [2X]**.

4. **Create your character and leave the coffin.** The tutorial starts on its own. If you installed the interface, its bars and panels appear on screen.

</Steps>

If the interface doesn't appear after joining, see [Interface troubleshooting](/getting-started/interface-troubleshooting/).

## Choosing a server

The official guides describe the server's systems without naming a specific server, so this wiki treats them as applying everywhere. Anything that turns out to be specific to RPG 04 gets the **RPG 04** label.

<Unverified q="Q-001">The official guides don't say which settings are specific to RPG 04, or what the "2X" in its name multiplies (XP, loot, gathering or something else).</Unverified>

<Unverified q="Q-002">The official guides only say to search for "Sangria Falls" in the server list. They don't cover how to pick RPG 04 among several Sangria Falls servers, a direct-connect address, or a password.</Unverified>

## After you join

- Follow the tutorial to the end. Every step pays XP, and it's where you pick your free first class. See [The Path of Blood tutorial](/getting-started/path-of-blood/).
- Set the language if the server isn't speaking English. See [Setting the language to English](/getting-started/language/).
- Need help? The official Discord is discord.gg/SangriaFalls.

## Common questions

### Can I play on PS5?

No. The official First steps guide says Sangria Falls only works on PC (Steam).

### A restart notice appeared at the top of the screen. What now?

The server restarts at set times each day. The notice appears 30 minutes before, with a sound, and becomes a countdown for the last 30 seconds. Extra restarts outside the usual times show a reason. Finish what you're doing, leave dungeons and events, and go to your castle or somewhere safe. The daily restart times aren't published (see [Q-003](/about/open-questions/#q-003)).
