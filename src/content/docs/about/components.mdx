This page is for people writing articles. Each example below uses real facts from the official guides, so it doubles as a check that the components render correctly. Import a component at the top of an `.mdx` file, then use it.

Some things happen automatically and need no component: breadcrumbs, labels from frontmatter, the work-in-progress notice, *Before you read* and *Related guides* (from `docs/coverage.yaml`), official sources with the last-verified date, and the *Copy summary for Discord* button.

## With and without the interface

Use this wherever the steps differ. The reader's choice is remembered across pages.

```mdx
<PlayModes>
  <Fragment slot="interface">Press **F10**. The MEDITATION panel opens anywhere on the map.</Fragment>
  <Fragment slot="chat">Type `.meditate` in chat. A numbered menu appears; type a number to choose, `0` to exit.</Fragment>
</PlayModes>
```

<PlayModes>
	<Fragment slot="interface">Press **F10**. The MEDITATION panel opens anywhere on the map.</Fragment>
	<Fragment slot="chat">Type `.meditate` in chat. A numbered menu appears; type a number to choose, `0` to exit.</Fragment>
</PlayModes>

## Commands

Never translate the command itself; only the description.

```mdx
<Command cmd=".meditate panel">Opens the meditation panel (with the interface).</Command>
```

<Command cmd=".meditate panel">Opens the meditation panel (with the interface).</Command>

## Filterable tables

Wrap any Markdown table. Filtering ignores accents, so "pao" finds "pão".

```mdx
<FilterTable placeholder="Filter currencies…">
| Currency | Used for |
|---|---|
| Ourosangue | Everyday purchases, prestige, evolutions |
</FilterTable>
```

<FilterTable placeholder="Filter currencies…">

| Currency | Comes from | Used for |
|---|---|---|
| Ourosangue | Events, Contracts, Market, Shadow Merchant, gathering | Shop, Vault, Arena, prestige, Transfusions, evolutions |
| Sangricoins | Rupture, Judgment, Tower, Online Reward, Battle Pass | Meditation, incubation speed-ups, some resets |
| Quitina | Outpost missions, Battle Pass | 2x XP for 30 minutes |
| Resonator | Arena, dungeons, Battle Pass | Sangrulho eggs |
| Crystals | Dungeons, drops | Pet attribute upgrades |

</FilterTable>
