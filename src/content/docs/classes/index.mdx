Every vampire starts as an **Awakened**. The 11 classes are taught by their **Masters** in the **Classes Hall** (City of Sangria Falls, via the teleport hub). Each class has its own weapons, abilities and bonuses, plus **3 evolutions**.

- **Your first class is free**, chosen during the tutorial. Others unlock through each Master's quest.
- **Unlocked classes are yours forever.** Switching costs 3,000 Ourosangue, and you keep everything.
- **Class bonuses only apply with the class weapon in hand.**
- **Try any class free** in the [Training Room](/classes/training-room/).
