## What makes this wiki different

The official guides explain each system on its own. This wiki connects them, so it can answer the questions you actually run into:

<CardGrid>
	<Card title="What should I do next?" icon="rocket">
		A walkthrough ordered by real unlock requirements, not guesswork.
	</Card>
	<Card title="Is this official?" icon="approve-check">
		Every claim is labelled: officially confirmed, community recommendation, or requires verification.
	</Card>
	<Card title="In English" icon="translate">
		Many official pages (all class pages, the command list) are only in Portuguese. We translate them.
	</Card>
	<Card title="With or without the interface" icon="laptop">
		Steps for ScarletInterface panels and for chat-only players.
	</Card>
</CardGrid>
