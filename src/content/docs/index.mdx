## Essential commands

Type these exactly as shown. The full list of 309 is on the [commands page](/reference/commands/).

<Command cmd=".menu">Opens the general menu (no interface needed).</Command>
<Command cmd=".lang en">Switches the server to English.</Command>
<Command cmd=".quest">Your active quests and their current step.</Command>
<Command cmd=".level">Your level, prestige and the next prestige cost.</Command>
<Command cmd=".mercado go">Teleports you to the city.</Command>
<Command cmd=".meditate">Opens the meditation menu.</Command>
